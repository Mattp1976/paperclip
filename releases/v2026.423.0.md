## The story this release tells

For most of Paperclip's life, an agent was a thing you gave a task to. This release is the first one where an agent is a thing that gives *other* agents a task. The delegation story is now end-to-end: a human routes work to a CEO, the CEO routes to a specialist, the specialist ships, the parent agent sees a review card, the human sees the outcome. Every other change in this version supports that single arc.

If you take only one thing from the notes below, take this: the unit of work is no longer the agent. It's the fleet.

## Highlights

- **One-tap `Route to`.** The Inbox has a single verb for moving work to an agent. Not assign, not hand off — `Route to`. Where the work is going, what the agent is called, and why you'd pick them is now decidable in one click.

- **Parent-agent review card.** When a child agent finishes a task, the parent sees a review surface with a one-line summary, an output preview, and Accept / Reject / Comment. The parent has an inbox the same way the human does.

- **Delegation graph on every AgentDetail page.** See who each agent reports to, who reports to them, and who they've handed work to recently — live, not a static chart.

- **Standup as the daily surface.** A briefing, not a dashboard. Three columns per agent: what closed, what's in flight, what's in the way. Quiet agents don't render. Copy-to-clipboard produces a Markdown digest ready to paste into email. *(Email transport itself is parked for next release; the digest is there.)*

- **Cost and outcome telemetry per agent.** Cost per task is visible on the Dashboard and on each AgentDetail page. Resolved-task counts sit next to spend so you can tell which agents are producing and which are expensive.

- **Two new fleet templates.**
  - **The Agent Collective** — CEO, CFO, Research Director. The smallest team that feels like a company. Designed as the demo fleet: one click, three agents, delegate to the CEO.
  - **Solo Consultant** — Chief of Staff, Account Lead, Comms & Admin. Three agents for a one-person practice.

- **Copy audit rolled through the product.** `Assign` became `Route to` everywhere it meant delegation. `Issue` stopped leaking into user-facing copy. Title Case buttons are sentence case. Sentence endings stopped arguing with each other. The product reads like one voice, because it now is.

## Improvements

- `AdvancedSection` rolled to three more pages; surface-level defaults stay lean, advanced is one click away.
- Delegation verb pinned in `VOICE.md` so it stops drifting in new copy.
- Fleet-template installer accepts templates with more agents, more projects, and more routines — the existing shape generalised without special-casing.
- Broken-windows log formalised at `broken-windows.md`; parked items live at `PARKED.md` with tags, so tradeoffs are audit-able rather than lost.
- Category vocabulary drafted — *fleet, standup, delegation graph, headcount* — pinned as a post in `posts/drafts/` for when the moment is right.

## Fixes

- Inbox routing no longer needs a round-trip through a modal for the common case.
- Cost summaries no longer double-count cancelled runs.
- Standup quietly drops agents with zero activity instead of rendering an empty card per idle agent.

## What's deliberately not in this release

A short list, because what you don't build is also part of the story:

- **Automatic email send of the daily digest.** The renderer is in; the transport isn't. Picked for a future release when we choose a provider.
- **Bulk actions on the Parent Review card.** No *accept all by this agent* yet — the delegation audit hasn't told us it's needed.
- **A template marketplace.** Two templates ship in-app. The install flow is real; the marketplace around it is scope for next quarter.

## Upgrade guide

No breaking schema changes. Existing companies and agents carry forward. The two new fleet templates appear in the template picker automatically — nothing to migrate.

If you previously wrote code against the `Assign` verb in copy strings or test IDs, the new verb is `Route to`. Search for the old one and update where it referred to delegation (the noun `assignee` is unchanged).
